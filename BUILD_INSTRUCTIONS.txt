Инструкция по сборке ShikiRIP Cinema
======================================

Требования
----------
- Node.js 22 (рекомендуется через nvm: nvm install 22 && nvm use 22)
- npm 10+

Шаги сборки
-----------

1. Установить зависимости:

   npm install

2. Собрать расширение для Chrome Web Store:

   npm run bundle:cws

   После завершения собранное расширение находится в папке dist/.
   Там же лежит manifest.json (MV3) — папку dist/ можно загружать в Chrome напрямую.

3. (Опционально) Собрать для Firefox:

   npm run bundle:firefox

Загрузка в браузер (для проверки)
-----------------------------------
Chrome / Edge:
  1. Открыть chrome://extensions
  2. Включить «Режим разработчика»
  3. Нажать «Загрузить распакованное расширение»
  4. Выбрать папку dist/

Firefox:
  1. Открыть about:debugging#/runtime/this-firefox
  2. Нажать «Загрузить временное дополнение»
  3. Выбрать файл dist/manifest.json
